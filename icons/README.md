# The icons directory README

```
icons
├── README.md
├── qlogo_icon_1024.png : PNG export of the master icon; input to util/createDesktopIcons.sh
├── qlogo_icon_1024.xcf : The single source of truth for the QLogo/Psychi icons, made with GIMP
├── macos/
│   └── Psychi.icns     : macOS icon file
├── windows/
│   ├── Psychi.ico      : Windows icon file
│   └── Psychi.rc       : Windows resource script embedding Psychi.ico
└── linux/
    └── hicolor/        : Freedesktop icon theme tree for common Linux desktops
```
